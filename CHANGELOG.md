# Changelog

## 0.2.0

- **Updates.** Linky checks GitHub for new versions and offers to update: a banner in the window, a notification and a tray item. On Windows it downloads and installs after you click Update. On macOS it opens the download page.
- **New typeface.** The app now uses Nunito Sans, with Cyrillic that reads better in Russian.
- **First-run snippets.** New installs start with a thank-you note and links to the author's portfolio, Behance and Telegram.
- **Copy.** Plain wording across the interface; the Russian version no longer uses "ё" or long dashes.

## 0.1.0

First public release: quick menu on Ctrl + Alt + V, library with folders, settings, onboarding, English and Russian, light and dark themes, Windows and macOS builds.
